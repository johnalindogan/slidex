UX audit · SlideX 0.1.13

Ranked by harm. P0 loses data or breaks a core task · P1 slows you down daily · P2 polish. "See" points to the artboard with the fix.

P0

#ScreenProblemWhy it hurtsFix
P0-1Media Manager · right-click"Delete file" sits in the same list as Duplicate and Remove, same weight, one click away.A slip deletes the original from disk. On a network share there is no Recycle Bin, so it is gone.Split the menu; "Move file to Recycle Bin…" in red, below a divider, on Shift+Del. Confirm dialog names the files, says it affects other playlists, warns about shares, offers "Remove from playlist only", focus starts on Cancel. See: Media Manager
P0-2Undocked windowOpened black; order wrong after Dock; nothing shows whether it is linked.The second screen shows nothing or the wrong list, and you can't tell which.Main window owns the state; the second window shows a skeleton until the first snapshot, a link chip at all times, pauses edits when the link drops, and Dock confirms "order kept". See: D · Second window
P0-3Cast panel"Connecting…" can sit with no time, step or cancel; failure is "Could not open a secure connection to the TV." with no next step.Casting is a core feature and the panel leaves you guessing whether to wait, retry or fix the firewall.Three named steps with a timer and Cancel; time out at 15 s; plain error with the firewall hint inline; Try again / Enter TV address; raw error and log path under Details. See: Cast

P1

#ScreenProblemWhy it hurtsFix
P1-1Controls · More toolsAbout 20 icon-only controls in one unlabeled row, mixing actions (screenshot) with settings (duration, transition).You hunt by hovering. Similar icons (mirror H/V, max modes, export graded/cropped) are easy to mix up.Replace the row with a Tools sheet: 4 labeled groups, type-to-find, key shown on every row. Settings-type controls also live in Settings. Bottom bar keeps about 12 primaries plus Music and Settings. See: Controls
P1-2Settings (4 places)Settings are split across More tools, Ken Burns, the shortcut editor and Cast.No single place to check how the app is set up; 0.2.0 adds music and render settings with nowhere to go.One Settings modal (Ctrl+,) with sections: Playback, Ken Burns, Music & beat sync, Music video, Cast, Second window, Keyboard shortcuts, Advanced. Existing modals become sections. See: Settings
P1-3Media Manager headerEmoji icon buttons (shuffle, new folder, save, load) with no labels; two folder emoji mean different things.Emoji render differently across Windows fonts and can't be read at a glance.Short text buttons with tooltips and keys, grouped Add · Organize · Window. See: Media Manager
P1-4Undock / Dock"Undock" is jargon; the toast "Media Manager undocked." doesn't say where it went.If the window opens on the other monitor, it looks like the panel just vanished."Open in window" / "Dock back", same key both ways (Ctrl+Shift+U), and the main window shows a "Media Manager is in its own window · Bring back" stub where the dock was.
P1-5Cast panel styleIts own blue palette and system font, and raw encoder names (libx264, h264_mf, h264_nvenc, h264_qsv).It looks like another app, and encoder names mean nothing without lookup.Unify on the glass tokens. Keep the blue (#9fd0ff) only as the app-wide "live / connected" accent, always with a dot and a word. Encoders become Auto / Compatible / Windows built-in / NVIDIA / Intel, with the raw name in small mono below. See: Cast
P1-6LandingCast is outlined in blue, so it reads as the default, though it's the least likely first step; Continue isn't emphasised; "Image Updates · advanced" is unclear.The most common action (Continue) takes a mouse hunt; the blue tile pulls the eye to the wrong place.Continue is the default (Enter); recent playlists listed inline; Make music video added; Cast, Settings, Shortcuts move to a quiet row; Image Updates moves to Settings › Advanced. See: Landing
P1-7Keyboard shortcutsKeys are only discoverable through the shortcut editor; tooltips don't show them.For a keyboard-driven app, you only learn keys by opening a modal.Every tooltip ends with its key; Tools sheet shows keys; ? opens a read-only cheat sheet; the editor moves into Settings.
P1-8All screensText at .3 and .45 white on #000/#141414 is about 2.4:1 and 4.4:1 (version line, "or drop files here", filename overlay, "reset" buttons).Fails 4.5:1; hard to read on a dim room monitor or a TV.Any readable text at .6 or more; keep .3 for decoration and disabled only. Mockups follow this.
P1-10Media Manager · editsRemove from playlist, Shuffle and drag-reorder can't be undone.One stray Shuffle scrambles a hand-ordered playlist with no way back.Ctrl+Z / Ctrl+Y for playlist edits (same history model as the timeline), plus an "Undo" button on the toast after Remove and Shuffle. Deleting files stays on the Recycle Bin, not undo.
P1-9ModalsNo visible focus ring in the screenshots; unclear which control has focus.Breaks keyboard use, which is the main way you drive the app.2 px white :focus-visible ring everywhere; trap focus in modals; Esc closes the topmost layer only; Enter runs the primary button.

P2

#ScreenProblemWhy it hurtsFix
P2-1Playlist libraryDates as "10/24/2026, 6:00:00 PM"; Delete as prominent as Load.Seconds are noise; the destructive button draws the eye."Oct 24, 6:00 PM"; Delete stays confirmed but moves right and quieter. Recent playlists also appear on Landing.
P2-2ToastRed action buttons on neutral messages.Red should mean "this destroys something".Neutral buttons; red only for destructive actions.
P2-3Ken Burns modal"400%" intensity with no reference point; long per-slide list without search.Hard to predict the result.Label slider ends (Subtle / Strong) and add the same filter field as the shortcut editor.
P2-4Bottom bar"1/7" with no spacing; seek bar has no label or time.Hard to read; not accessible to the keyboard."3 / 7", seek is a labelled slider with arrow keys.
P2-5FontsPlus Jakarta Sans and JetBrains Mono come from Google Fonts.Offline, the fallback font swaps in and layouts shift.Bundle the woff2 files with the app (see Porting note).
P2-6Media Manager"3 selected" badge doesn't say what an action will affect.Unclear whether Delete or Shuffle hits the selection or the whole list.Actions that use the selection say so: "Remove 3", "Move 3 files to Recycle Bin…".
