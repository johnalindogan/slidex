6 · JS changes

  • Layer stack. openLayer(id) / closeTop(): focus trap, return focus to the opener, Esc closes the top, Enter runs [data-primary].
  • Key scopes. While #amv is open, single letters (L W R G T) belong to the wizard and global keys pause. One table maps scope → key → command so the shortcut editor can check conflicts per scope.
  • Wizard state. step enum + a project JSON {id,name,media[],song,options,plan:{shots[]},locks,renders[]} saved in app data, never beside sources.
  • Rust side. Commands amv_analyze(project), amv_render(plan), amv_cancel(job); events amv://progress {phase,file,i,n,eta}, render://progress {pct,shot,reused,eta}. Cache key = path + size + mtime + analyzer version. Render keeps per-shot segments so an edit only redoes changed shots, then concatenates.
  • Undo / redo. Every plan edit (reorder, lock, swap, trim, split, merge, transition, Ken Burns, Regenerate, style change, beat-grid apply) goes through commit(label, nextPlan), which pushes the previous plan onto past (cap 100) and clears future. Plans are small JSON, so store whole snapshots, not diffs. Ctrl+Z / Ctrl+Y (and Ctrl+Shift+Z) walk the stacks; button tooltips name the step ("Undo Lock shot 12"). History is saved with the project, so it survives closing the wizard. Render, Analyze and selection changes are not undo steps.
  • Timeline. Shot width = flex-grow: beats; ticks are a CSS gradient driven by --px-per-beat; the playhead follows audio.currentTime.
  • Music clock. One <audio> drives the slide scheduler from beat times + syncOffsetMs (saved). If a cast session is active, show the banner; the TV stream keeps fixed timing.
  • Second window. Main owns state. Main sends sw://snapshot {v,state} on open and sw://patch {v,ops} after; the window sends sw://intent {op} only. Heartbeat every 2 s; no beat for 6 s → "Not linked", editing paused; reconnect asks for a snapshot. That fixes both QA bugs: skeleton until the first snapshot (no black), and only main changes order.
  • Later "Render & Cast". Leave a slot after Cast it… in #amvDone; nothing else depends on it.
